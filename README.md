# 2D Mobile Platformer Game

A complete 2D mobile platformer game built in Unity with the following features:

## Features
- Player movement with jumping and double jump
- Mobile touch controls
- Collectible coins
- Enemies with AI
- Multiple levels
- Score system
- Mobile-optimized UI
- Sound effects and background music

## Controls
- **Mobile**: Touch left/right sides of screen to move, tap to jump
- **PC**: WASD or Arrow keys to move, Space to jump

## Project Structure
- `Assets/Scripts/` - All game scripts
- `Assets/Prefabs/` - Game objects and prefabs
- `Assets/Scenes/` - Game levels
- `Assets/Sprites/` - Game graphics
- `Assets/Audio/` - Sound effects and music

## Setup Instructions
1. Open the project in Unity 2022.3 LTS or later
2. Open the MainMenu scene
3. Press Play to start the game

## Mobile Build
- Set target platform to Android/iOS in Build Settings
- Configure player settings for mobile optimization
- Build and deploy to device
